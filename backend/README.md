# Project Camp — Backend

The Express 5 + MongoDB API that powers Project Camp. Base path `/api/v1`.

```bash
npm install
cp .env.example .env   # then fill in MONGO_URI and the token secrets
npm run dev            # http://localhost:8000
npm run seed           # optional: reset the database and load demo data
```

Setup instructions and the environment variable reference live in the [root README](../README.md). Every endpoint is documented in [docs/API.md](../docs/API.md).
